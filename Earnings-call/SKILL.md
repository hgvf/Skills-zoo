我會給你法說會或電話會議逐字稿。又或是給你法說會影音檔或連結，請自行先產生逐字稿。

1. 首先你必須做個公司業務與重大告知、消息的摘要
2. 後續逐一分析提到的重要內容、資訊，並以外部或公開資訊交叉比對等等
3. 最後用表格呈現 QA 內容，包含提問者、問題、以及公司回應
4. 整理會議後盤後股價狀況，以及稍微分析前三次電話會議後，股價變化，用表格或圖表呈現

另外 session 標題請改成 YYYY_QQ_TICKER（ex. 2026_Q2_INTC）

## 額外任務
每次整理完後，請輸出以下格式的 JSON（單一物件、陣列，或 {"calls":[...]} 皆可）：

| 欄位                       | 型別               | 必填       | 說明                                                                 |
| ------------------------ | ---------------- | -------- | ------------------------------------------------------------------ |
| `ticker`                 | `string`         | ✅        | 股票代號，如 `"NVDA"`、`"2330.TW"`。會用於文件 ID。                              |
| `year`                   | `number`（整數）     | ✅        | 財報年度，如 `2026`，不要加引號。                                               |
| `quarter`                | `string`         | ✅        | 季度，如 `"Q2"`、`"Q4"`、`"FY"`（全年）。                                     |
| `company`                | `string`         | 選填       | 公司全名。省略時預設等於 `ticker`。                                             |
| `date`                   | `string`         | 選填（強烈建議） | 會議日期，格式為 `YYYY-MM-DD`。沒填的話卡片會出現，但不會出現在時間軸節點上。                      |
| `summary`                | `string`         | 選填       | 一句話總結，顯示在卡片上方，建議簡潔。                                                |
| `highlights`             | `array`          | ✅        | 重點清單，格式見下方。                                                        |
| `highlights[].text`      | `string`         | ✅        | 一條重點內容。空字串會被自動丟棄。                                                  |
| `highlights[].sentiment` | `string`         | ✅        | 只接受 `"bullish"`、`"bearish"`、`"neutral"`；其他值一律視為 `neutral`。         |
| `watch`                  | `string[]`（字串陣列） | 選填       | 未來重點看點：之後應追蹤的催化劑、待確認事項、下季該驗證的指引。介面會在卡片下方獨立成一張「🔮 未來重點看點」卡；舊資料沒有也不影響。 |

### 重要規則
- 文件 ID = `ticker-year-quarter`（小寫、非英數轉 `-`）。同一場會議重貼是更新、不會重複——所以 year/quarter 要正確。
- sentiment 三選一，大小寫不拘，但不要用中文或其他字（會被當成 neutral）。
- 卡片整體顏色（左邊框 + 時間軸節點色 + 月曆色塊）依 highlights 判定：**bullish 的數量必須「大於 bearish + neutral 的總和」才算整體偏多（綠）**；反之 bearish 數量大於 bullish + neutral 才算偏空（紅）；兩者都不成立則為中性（灰）。
- year 是數字不加引號；其餘字串都要引號。
- 建議 highlights 涵蓋這幾類：營運/財務、財測展望、供應鏈訊號、風險；每條精簡一句、用繁體中文。
- 也要附上公司派的展望與未來發展方向；有大變化（營利結構調整、新產品、策略轉向等）也必須放進 highlights，並把「之後要盯的事」放進 `watch`。
