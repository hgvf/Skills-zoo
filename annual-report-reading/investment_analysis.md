# Buy-Side Investment Analysis Rules

## 1. 重大性排序

所有資訊依下式排序：

```text
重大性
× 未來 1～3 年獲利影響
× 證據可信度
× 可量化程度
× 與核心產品關聯度
```

優先保留：

- 影響營收、毛利率或自由現金流
- 可能改變市場份額
- 可能形成未來催化劑
- 可能造成估值重估
- 可能造成財務或治理風險

---

## 2. 成長驅動拆解

每個 Growth Driver 必須說明：

- 相關產品或事業部
- 目前階段
- 預計時間
- 可能影響
- 成功所需條件
- 證據

### 高影響

- 可能成為主要營收來源
- 可能顯著改善毛利率
- 可擴大市場份額
- 可能改變公司估值方法

### 中影響

- 對部分產品或區域有實質貢獻
- 對公司整體影響有限但可量化

### 低影響

- 仍偏早期
- 市場規模小
- 尚無客戶或量產證據

---

## 3. Bull／Base／Bear

### Bull Case

至少包含：

- 必須發生的條件
- 受益產品
- 毛利率或營收改善來源
- 可驗證的確認指標

### Base Case

描述目前最合理情境，不應等於管理層最樂觀目標。

### Bear Case

至少包含：

- 觸發條件
- 受影響產品或部門
- 財務影響路徑
- 可觀察的負面指標

---

## 4. Stance

| 評級 | 判定條件 |
|---|---|
| bullish | 核心業務成長、毛利與現金流改善，催化劑明確，風險可控 |
| slightly_bullish | 基本面改善但仍有執行、景氣或估值風險 |
| neutral | 利多利空大致平衡，缺乏明確催化劑 |
| slightly_bearish | 成長放緩、毛利承壓、庫存或現金流惡化 |
| bearish | 核心需求、競爭力或財務結構明顯惡化 |

只依年報內容評估基本面；若沒有股價與估值資料，不得評論是否便宜。

---

## 5. 必追蹤指標

依公司類型選擇：

| 公司類型 | 追蹤指標 |
|---|---|
| 半導體 | 稼動率、ASP、良率、CapEx、庫存天數、新產品量產 |
| 設備 | 訂單、Backlog、Book-to-bill、客戶CapEx |
| 材料 | 原料價差、長約、稼動率、產品認證 |
| SaaS | ARR、NRR、RPO、CAC、自由現金流率 |
| 零售 | 同店銷售、庫存、毛利率、門市數 |
| 工程 | Backlog、得標率、專案毛利、營運資金 |
| 生技 | 臨床進度、現金跑道、授權、監管里程碑 |
